
# Dataset

This directory is reserved for local dataset files and is not intended to contain raw datasets in Git.

The dataset will contain examples of two explicitly defined classes:

- `HELP`
- `NOT_HELP`

Dataset documentation will record the collection method, class definitions, participant-level splits, consent considerations, and preprocessing steps.

Do not commit identifiable recordings, personal data, or third-party datasets unless their licenses and consent terms explicitly permit redistribution.
